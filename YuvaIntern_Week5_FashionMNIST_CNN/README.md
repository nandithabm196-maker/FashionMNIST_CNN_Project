# YuvaIntern Week 5 – Fashion-MNIST CNN

## Project
Fashion-MNIST Image Classification using a Convolutional Neural Network (CNN).

## Objective
Build, train and evaluate a deep learning model that classifies 28×28 grayscale clothing images into 10 categories.

## Run
```bash
pip install -r requirements.txt
python fashion_mnist_cnn.py
```

The first run downloads the Fashion-MNIST dataset through Keras.

## Generated outputs
- `outputs/model_summary.txt`
- `outputs/training_history.csv`
- `outputs/training_curves.png`
- `outputs/training_accuracy.png`
- `outputs/training_loss.png`
- `outputs/confusion_matrix.png`
- `outputs/classification_report.txt`
- `outputs/sample_predictions.png`
- `outputs/fashion_mnist_cnn.keras`

## Important
Do not type invented accuracy/precision/recall/F1 values into the report. Run the script and copy the actual values from `outputs/classification_report.txt`.
