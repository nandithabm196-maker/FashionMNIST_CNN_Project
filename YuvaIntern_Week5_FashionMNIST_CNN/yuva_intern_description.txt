This report presents an end-to-end deep learning project for image classification using the Fashion-MNIST dataset and a Convolutional Neural Network (CNN) implemented with Python and TensorFlow/Keras. The objective was to design, train, validate and evaluate a neural network capable of classifying 28×28 grayscale clothing images into ten categories: T-shirt/top, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag and Ankle boot. The workflow includes loading a publicly available dataset, preprocessing and normalizing image pixels, creating a validation split, designing the CNN architecture, selecting appropriate hyperparameters, training the model and evaluating it on an unseen test set. The network uses convolutional layers for visual feature extraction, max-pooling for spatial reduction, batch normalization for training stability, a dense layer for feature combination and dropout to reduce overfitting. Adam optimization and sparse categorical cross-entropy are used during training. Early stopping and learning-rate reduction are included to improve training efficiency and generalization. Model performance is evaluated using accuracy, precision, recall, F1-score and a confusion matrix. Training and validation curves are also generated to analyze convergence and possible overfitting. The report discusses implementation challenges such as class similarity, computational resources and hyperparameter selection, along with practical solutions. The project provides hands-on experience with the complete deep learning lifecycle, from dataset preparation to model evaluation, and creates a reproducible foundation for future improvements such as data augmentation, transfer learning and explainable AI.
